# Chat local — V0.3

Requer Node.js 18 ou superior. No terminal, entre na pasta server e execute npm install e npm start. Abra http://127.0.0.1:8765 no navegador. Em outro terminal na mesma pasta, execute npm run simulate. Ctrl+C interrompe o simulador. O servidor escuta somente na interface local. O jogo publicado no GitHub Pages permanece independente. Para OBS, use a URL local como fonte de navegador. Não há conexão real com TikTok, credenciais ou integração de presentes. O simulador envia comentários FOGO e LEITE de 100 espectadores fictícios. O intervalo por usuário é de 200 milissegundos. Use apenas uma instância do jogo para acompanhar uma partida.
